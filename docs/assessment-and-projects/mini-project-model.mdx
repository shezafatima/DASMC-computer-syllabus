# Mini Project Model

Each major topic should conclude with a small practical task or mini project.
Projects should be short enough to complete within the teaching schedule and should
reinforce the skill just learned.

| Area | Task |
|---|---|
| **Computer / Digital Skills** | Organize files or complete a digital-safety challenge. |
| **Office** | Create a short document, presentation or simple data sheet. |
| **Canva** | Create a poster, infographic, card or campaign visual. |
| **Scratch** | Create an animation, quiz, story or game. |
| **AI** | Solve a small productivity/creative task and evaluate the output. |
| **Web** | Create a simple webpage appropriate to the grade. |
