### 💡 Computer systems

**Concept:** A computer system is an integrated team of hardware and software working together to process, store, and output information.

**Example:** Think of a computer system like a busy restaurant: the CPU is the chef, the RAM is the counter where plates are prepped, and the hard drive is the pantry in the back.

**Why it matters:** Understanding how the parts work together helps you figure out what to fix when something breaks.

**Did you know?** A bigger computer case doesn't mean it's faster! It's the tiny chips inside that determine how fast a computer system really is.

### ⚙️ File organization

*Keep your digital workspace clean so you never lose an assignment.*

1. **Create a main folder on your desktop and name it with the current school year (e.g., '5th Grade 2024').** This keeps everything for the year in one central location.
2. **Inside that folder, create separate sub-folders for each subject (Math, Science, English).** Treat these like physical binders for your classes.
3. **When you start a new project, save it immediately into the correct subject folder.** Don't just save everything to the desktop or the Downloads folder!
4. **At the end of a semester, create an 'Archive' folder to store old work.** This keeps your main folders clean and focused on what you are doing right now.
5. **Save or finish the activity.** Use the File menu or the activity button, then wait for confirmation that the work is complete.

💡 **Tip:** Use numbers at the beginning of folder names (e.g., '01_Math', '02_Science') to force the computer to put them in the order you want.

### ⚙️ Productivity shortcuts

*Work like a professional by keeping your hands on the keyboard.*

1. **Press 'Ctrl + F' (or Cmd + F on a Mac) to quickly find a word or phrase in a long document.** A small search box will appear. Type your word, and it will highlight every time it appears on the page.
2. **Use 'Windows Key + D' (or Cmd + F3) to instantly minimize all windows and see your desktop.** This is great when you need to grab a file hidden behind a messy pile of open apps.
3. **Press 'Ctrl + P' to quickly open the print menu for any document or webpage.** This saves you from digging through the File menu.
4. **Press 'Ctrl + Z' to 'Undo' your last action.** If you accidentally delete a whole paragraph, just press Ctrl + Z and it will pop right back!
5. **Save or finish the activity.** Use the File menu or the activity button, then wait for confirmation that the work is complete.

💡 **Tip:** Shortcuts are called shortcuts for a reason! They can save you hours of clicking over a school year.

### ⚙️ Basic troubleshooting

*Fix common computer problems yourself before asking for help.*

1. **If a program freezes, do not click the mouse 50 times in a row.** This will only confuse the computer more! Give it a minute to catch up.
2. **If your internet is suddenly slow or disconnected, check if other devices in the room are working.** If everything is broken, the router might need a restart. If it's just your computer, check your Wi-Fi settings.
3. **If you can't find a file you saved, click the start menu and use the 'Search' bar.** Type part of the filename and let the computer hunt for it.
4. **If an error message pops up, read the whole message before clicking OK.** Often, the message tells you exactly how to fix the problem.
5. **Save or finish the activity.** Use the File menu or the activity button, then wait for confirmation that the work is complete.

💡 **Tip:** The golden rule of IT: When in doubt, turn it completely off and turn it back on again!

### 💡 Digital organization

**Concept:** Digital organization is the disciplined practice of keeping your files, emails, and accounts tidy, properly named, and easy to find.

**Example:** Giving your science report a clear name like 'Volcano_Diagram_Final.png' instead of just 'image123.png' is digital organization in action.

**Why it matters:** A messy computer slows you down and causes stress when a deadline is approaching. In Grade 5, connect this idea to a small project so you can see it working instead of only memorising a definition.

**Did you know?** Using the 'Search' bar for everything is not the same as being organized. A well-organized folder system is always faster and more reliable.
