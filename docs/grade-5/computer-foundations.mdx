# 🖥️ Computer Foundations

*Grade 5 — Digital Problem Solver*

Topics covered this grade:

- **Computer systems**
- **File organization**
- **Productivity shortcuts**
- **Basic troubleshooting**
- **Digital organization**

---

### 💡 Computer systems

**Concept:** A computer system includes all the hardware and software working together to process and store information.

**Example:** Think of a system like a team: the CPU is the captain, the RAM is the short-term memory, and the hard drive is the library.

---

### ⚙️ File organization

1. Create a main folder for the current school year.
2. Use sub-folders for each subject (e.g., Math, Science, English).
3. Archive old work in a separate folder to keep your main workspace clean.

---

### ⚙️ Productivity shortcuts

1. Use Ctrl + F to quickly find a word or phrase in a document or webpage.
2. Use Windows + D (or Cmd + F3) to hide all windows and see your desktop instantly.
3. Use Ctrl + P to open the print menu for any document.

---

### ⚙️ Basic troubleshooting

1. If your internet is slow, check if other devices are working or try restarting the router.
2. If you can't find a file, use the 'Search' bar in your file explorer.
3. Look for error messages on the screen and try searching for what they mean online.

---

### 💡 Digital organization

**Concept:** Digital organization is the practice of keeping your files, emails, and accounts tidy and easy to find.

**Example:** Giving your files clear names like 'Volcano_Diagram_Final.png' instead of 'image123.png' is a key part of organization.
