# 🖥️ Computer Foundations

*Grade 4 — Digital Creator*

Topics covered this grade:

- **Hardware and software**
- **Operating systems**
- **File and folder management**
- **Typing**
- **Keyboard shortcuts**
- **Basic troubleshooting**

---

### 💡 Hardware and software

**Concept:** Hardware includes the physical parts of a computer system, while software includes the operating system and applications that run on it.

**Example:** The CPU and Hard Drive are internal hardware; the operating system is system software.

---

### 💡 Operating systems

**Concept:** The operating system is the most important software that runs on a computer, managing memory, processes, and all of its software and hardware.

**Example:** Common operating systems include Windows, macOS, and Linux.

---

### ⚙️ File and folder management

1. Use the 'File Explorer' (Windows) or 'Finder' (Mac) to see all your work.
2. Create a logical folder structure (e.g., Grade 4 > Science > Projects).
3. Rename files clearly so you can find them later (e.g., 'Solar_System_Report_v1').

---

### 💡 Typing

**Concept:** Accurate typing is an essential skill that allows you to communicate your ideas effectively on a computer.

**Example:** Aiming for 20-30 words per minute with high accuracy is a great goal for Grade 4.

---

### ⚙️ Keyboard shortcuts

1. Use Ctrl + Z to undo a mistake you just made.
2. Use Ctrl + A to select everything in your document or folder.
3. Use Alt + Tab to quickly switch between open programs.

---

### ⚙️ Basic troubleshooting

1. If a program freezes, try closing it and opening it again.
2. Check that all cables (like the mouse or power) are plugged in securely.
3. Restart the computer if it is acting slow or not responding.
