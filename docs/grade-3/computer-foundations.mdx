# 🖥️ Computer Foundations

*Grade 3 — Digital Explorer*

Topics covered this grade:

- **Computer hardware and software**
- **Operating system basics**
- **Keyboard and mouse skills**
- **Typing practice**
- **Files and folders**
- **Simple shortcuts**

---

### 💡 Computer hardware and software

**Concept:** Hardware is the physical parts of a computer you can touch, while software is the programs that tell the hardware what to do.

**Example:** The monitor is hardware; the browser you use to visit websites is software.

---

### 💡 Operating system basics

**Concept:** The operating system (OS) is the main software that manages everything on the computer.

**Example:** Windows and macOS are examples of operating systems that help you open apps and save files.

---

### ⚙️ Keyboard and mouse skills

1. Practice using the mouse to click small icons and menu items accurately.
2. Use the keyboard to type longer sentences, using the Shift key for capital letters.
3. Learn to use the 'Right Click' to see more options for a file or folder.

---

### 💡 Typing practice

**Concept:** Typing practice helps you find letters on the keyboard quickly so you can write faster.

**Example:** Using a fun typing game for 10 minutes a day can help you become a keyboard expert.

---

### ⚙️ Files and folders

1. Right-click on the desktop and choose 'New' then 'Folder.'
2. Give your folder a name like 'My School Work.'
3. Drag your files into the folder to keep them organized.

---

### ⚙️ Simple shortcuts

1. Press Ctrl + C to copy an item you have selected.
2. Press Ctrl + V to paste the copied item somewhere else.
3. Press Ctrl + S to quickly save your work.
